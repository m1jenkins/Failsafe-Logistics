# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1sAGDuQUiFJdvAOZBimFHwEejd699kYcT

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## AI Assistant Guidelines

> [!IMPORTANT]
> **Git Commit & Push Requirement:** 
> Whenever you make a change to the codebase, you must always commit the changes and push them to git (`git add`, `git commit -m "..."`, and `git push`) so the user's repository stays updated automatically.
